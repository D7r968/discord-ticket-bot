# 🎫 بوت التذاكر — ديسكورد

بوت تذاكر دعم كامل **بشكل فخم**: تضغط زر واحد → تطلع لك قائمة (شراء من متجر / استفسار / حل مشكلة) → تنفتح لك قناة خاصة في القسم المناسب. كمان فيه نظام حماية من المنشن: أول منشن تحذير، والثاني تايم أوت ٣ ساعات.

## ٢) إنشاء البوت في ديسكورد

1. ادخل https://discord.com/developers/applications
2. اضغط **New Application** وسمّيه (مثلاً Ticket Bot).
3. من القائمة اليسرى → **Bot**:
   - اضغط **Reset Token** وانسخ التوكن (يظهر مرة واحدة بس).
   - انزل تحت → **Privileged Gateway Intents**:
     - `SERVER MEMBERS INTENT` → مو ضروري.
     - `MESSAGE CONTENT INTENT` → **فعّله فقط إذا تبي سجل المحادثة يحفظ نص الرسائل كامل**. (اختياري)
   - احفظ التغييرات.
4. من **OAuth2 → General** انسخ **Application ID** (هذا هو CLIENT_ID).
5. من **OAuth2 → URL Generator**:
   - Scopes: `bot` + `applications.commands`
   - Permissions: `Manage Channels` + `Moderate Members` (للتايم أوت) + `Send Messages` + `Embed Links` + `Attach Files` + `Read Message History`
   - افتح الرابط الناتج وضِف البوت لسيرفرك.

> ⚠️ مهم: رتبة البوت لازم تكون **أعلى** من رتبة الدعم، عشان يقدر يضبط صلاحيات قنوات التذاكر.

---

## ٣) تشغيل البوت

1. افتح ملف **`.env`** (بالمفكرة) وحط:
   ```env
   DISCORD_TOKEN=التوكن_اللي_نسخته
   CLIENT_ID=الآي_دي_حق_التطبيق
   GUILD_ID=آي_دي_سيرفرك
   ```
   - آي_دي السيرفر: فعّل **Developer Mode** من إعدادات ديسكورد → كلك يمين على السيرفر → Copy Server ID.
2. دبل كلك على **`start.bat`**.
   - أول مرة بيثبّت المكتبات لحاله (يحتاج إنترنت).
   - إذا كل شي تمام بيطلع: `تم تسجيل الدخول: اسم_البوت`.
3. لا تسكّر نافذة البوت وهو شغال.

## ٤) إعداد البوت داخل السيرفر

| الأمر | الوظيفة |
|---|---|
| `/setup channel:#قناة` | يرسل لوحة فتح التذاكر في القناة (مع خيار `image` لرفع صورة) |
| `/panel` | يعيد إرسال اللوحة في نفس القناة |
| `/banner image:` | يغيّر صورة البانر |
| `/close` | يغلق التذكرة الحالية (مع تأكيد) |
| `/add user:@عضو` | يضيف عضو للتذكرة |
| `/remove user:@عضو` | يشيل عضو من التذكرة |
| `/rename name:اسم` | يغيّر اسم قناة التذكرة |

**الخطوات:**
1. سوّ قناة مثل `#الدعم` وخلّها للقراءة فقط للجميع.
2. اكتب `/setup channel:#الدعم` → بتنرسل اللوحة الفخمة وفيها زر «اضغط لفتح تذكرة».
3. العضو يضغط الزر → تطلع قائمة فيه ٣ خيارات:
   - 🛒 **شراء من متجر** → قناة `purchase-001`
   - ❓ **استفسار** → قناة `inquiry-002`
   - 🛠️ **حل مشكلة** → قناة `problem-003`
4. القناة الخاصة بتنفتح مع رسالة ترحيب فيها الأسئلة اللي لازم يجاوب عليها، وهو وفريق الدعم بس اللي يشوفونها.

---

## ★ نظام المنشن (تحذير → تايم أوت)

- أي عضو يمنشن البوت **المرة الأولى** → البوت يردّ عليه بتحذير: «المنشن الثاني = تايم أوت ٣ ساعات».
- إذا منشن **مرة ثانية خلال ٢٤ ساعة** → البوت يعطيه **تايم أوت ٣ ساعات** ويعلن في القناة.
- التحذير ينتهي بعد ٢٤ ساعة (تقدر تغيّرها من `config.json`).
- ❗ لازم البوت يملك صلاحية **Timeout Members / Moderate Members** ورتبته تكون **أعلى** من رتبة اللي بيمنشنه، وإلا بيقول «ما عندي صلاحية».
- لا يشتغل التحذير على رسائل النظم / أوامر السلاش، والبوت ما يحذّر نفسه.

---

## ٥) الصورة (البانر)

عندك طريقتين:

1. **من الملفات:** حط الصورة في مجلد `images` وسمّها `banner.png`
   (أو أي صورة، البوت بياخذ أول صورة يلقاها).
2. **من ديسكورد:** `/banner image:صورة.png` — بتنحفظ تلقائياً في `images/banner.png`.

الصورة تظهر في لوحة التذاكر وداخل رسالة الترحيب بكل تذكرة جديدة.

> إذا ما حطيت صورة، البوت يشتغل عادي بس بدون صورة.

## ٦) إعدادات متقدمة — `config.json`

| الحقل | الشرح |
|---|---|
| `supportRoleId` | آي_دي رتبة الدعم (بتنضاف لكل تذكرة تلقائياً) |
| `categoryId` | آي_دي قسم (Category) توضع فيه قنوات التذاكر — إذا فاضي يسوي قسم `Tickets` |
| `logChannelId` | آي_دي قناة السجلات (يوصلها سجل كل تذكرة مغلقة + ملف txt) |
| `ticketLimit` | كم تذكرة مفتوحة مسموحة للعضو الواحد (افتراضي 1) |
| `color` | لون الـ Embed (مثل `#5865F2`) |
| `panelTitle` / `panelDescription` / `panelButtonLabel` | نصوص لوحة التذاكر |
| `ticketWelcomeTitle` / `ticketWelcomeDescription` | نصوص رسالة الترحيب داخل التذكرة |
| `mentionWarnHours` | كم ساعة يبقى تحذير المنشن صالح (افتراضي 24) |
| `mentionTimeoutHours` | مدة التايم أوت بعد المنشن الثاني بالساعات (افتراضي 3) |
| `mentionTimeoutEnabled` | `true`/`false` لتفعيل أو تعطيل التايم أوت |
| `bannerFile` | مسار صورة مخصصة (اختياري — يلغي البحث في مجلد images) |

> أسماء الأنواع وألوانها وأسئلتها موجودة في `ticketTypes.js` وتقدر تعدّلها مباشرة.

بعد تعديل `config.json` أعد تشغيل البوت.

---

## ٧) وش يصير عند الإغلاق؟

1. العضو أو الدعم يضغط 🔒 / يكتب `/close`.
2. تأكيد → البوت:
   - يحفظ سجل المحادثة في `transcripts/purchase-001-<id>.txt` (حسب النوع)
   - يرسل السجل لقناة السجلات (إذا محددة)
   - يرسل نسخة للسجل في خاص صاحب التذكرة
   - يحذف القناة بعد ٤ ثواني

> السجل يحفظ نص الرسائل كامل فقط إذا فعّلت **Message Content Intent** (خطوة ٢).

## ٨) مشاكل شائعة

| المشكلة | الحل |
|---|---|
| `An invalid token was provided` | التوكن غلط أو ناقص — أعد نسخه في `.env` |
| الأوامر ما تظهر | تأكد `GUILD_ID` صح، وأعد تشغيل البوت، وحدّث ديسكورد (Ctrl+R) |
| `Missing Permissions` | رتبة البوت تحت رتبة الدعم أو ناقصها صلاحيات |
| البوت ما يفتح تذكرة | تأكد عنده `Manage Channels` وأن رتبته فوق |
| التايم أوت ما يشتغل | تأكد عنده `Moderate Members` وأن رتبته أعلى من رتبة العضو |
| الصورة ما تظهر | تأكد اسم الملف ينتهي بـ png/jpg ومو ملف تالف |
